# 💍 Wedding Photo Select

스튜디오에서 받은 수백~수천 장의 웨딩 원본 사진을 **신랑·신부가 각자 휴대폰으로 넘겨보며 점수를 매기고**,
마음에 드는 사진을 **최종셀렉**해서 원본을 한 번에 받는 프로그램입니다.

- 내 컴퓨터에서 돌아가는 **셀프 호스팅** 방식이라 사진이 다른 서버에 올라가지 않아요
- 프로그램 **하나만 실행**하면 끝 (설치할 것 없음, 코딩 몰라도 OK)
- 모든 파일이 바탕화면의 **폴더 하나**에 — 다 쓰면 **폴더째 휴지통에 버리면 삭제 끝**
- 무료 서비스 **Tailscale** 을 버튼 몇 번으로 연결해서 휴대폰/배우자도 인터넷 주소로 접속

## 기능

| | |
|---|---|
| 📱 사진 보기 | 좌우 **스와이프**, 두 손가락 **핀치 줌**, 더블탭 확대 (크게 확대하면 원본 화질) |
| ⭐ 점수 | 신랑·신부 **각자 1~5점**. 상대 점수는 같이 보이지만 바꿀 수는 없어요 |
| ♥ 최종셀렉 | 점수와 별도로 둘이 함께 쓰는 최종 목록 |
| 🔍 필터 | "둘 다 4점 이상", "신부 5점만", "♥만", "아직 안 본 것만" 등으로 걸러서 넘겨보기 |
| ▦ 목록 | 화면 크기에 맞춰 한 페이지씩 보기, **번호/파일명 입력해서 바로가기** |
| 🏆 이상형 월드컵 | 후보(필터 결과 · 최종셀렉 · 내 픽 · 내 4점 이상)에서 **최종 N장**만 남을 때까지 두 장씩 골라서 줄이기. 결과는 **사람마다 따로 저장**(필터 → 🏆 신랑 픽 / 신부 픽), 남은 사진에 **별점 일괄 부여**, 최종셀렉에 추가 · 교체. 셀렉 화면 별 옆에 사진별 **몇 승 몇 패** 표시 |
| ⬇ 다운로드 | 최종셀렉 **원본 zip** (점수 목록 txt 포함) |
| ↺ 초기화 | 셀렉 화면: 내 점수 / 최종셀렉 비우기 · 관리 화면: 전체 초기화. **초기화 전 자동 백업 → 되돌리기 가능** |
| 🔒 비밀번호 | 사람마다 다른 비밀번호 — **비밀번호로 누구인지 구분**해서 로그인 |
| 💾 저장 | 점수는 자동 저장. 껐다 켜도, 다시 접속해도 그대로 |
| ⌨️ PC | ← → 이동, 1~5 점수, 0 취소, F 최종셀렉, G 목록 |

## 설치 & 실행

설치 과정은 없어요. **zip 을 받아서 압축을 풀고, 안에 있는 파일을 더블클릭**하면 끝입니다.

👉 **[다운로드 페이지 (Releases)](https://github.com/Haeryangkim/wedding-photo-select/releases/latest)**

| 내 컴퓨터 | 받을 파일 |
|---|---|
| 🍎 Mac (Apple 칩 · Intel 모두) | `WeddingSelect-macos.zip` |
| 🪟 Windows | `WeddingSelect-windows.zip` |

### 🍎 Mac

1. `WeddingSelect-macos.zip` 을 받아서 더블클릭 → **`웨딩 사진 셀렉`** 폴더가 생겨요
2. 이 폴더를 **바탕화면**(또는 원하는 곳)으로 옮겨요
3. 폴더 안의 **`웨딩 사진 셀렉 시작`** 을 더블클릭
4. 처음 한 번은 *"Apple에서 확인할 수 없습니다"* 창이 떠요. 앱스토어 밖에서 받은 프로그램이라 뜨는 정상적인 안내예요.
   - **완료** 를 누르고 → **시스템 설정 → 개인정보 보호 및 보안** → 아래쪽의 **"그래도 열기"** 클릭
   - 다시 **`웨딩 사진 셀렉 시작`** 을 더블클릭 → **열기**
   - (구형 macOS 는 파일을 **우클릭 → 열기 → 열기**)
5. 터미널 창이 하나 뜨고, 브라우저에 **관리 화면**이 자동으로 열려요

### 🪟 Windows

1. `WeddingSelect-windows.zip` 을 받아서 **우클릭 → 압축 풀기(모두 추출)** → **`웨딩 사진 셀렉`** 폴더가 생겨요
2. 이 폴더를 **바탕화면**(또는 원하는 곳)으로 옮겨요
3. 폴더 안의 **`웨딩 사진 셀렉 시작`** 을 더블클릭
4. 처음 한 번은 *"Windows의 PC 보호"* 창이 떠요 → **추가 정보** → **실행**
5. 검은 창이 하나 뜨고, 브라우저에 **관리 화면**이 자동으로 열려요
   - "방화벽" 창이 뜨면 **허용** 을 눌러주세요 (외부 공유용, 취소해도 동작은 해요)

### 폴더 구성

처음 실행하면 폴더 안에 `사진`, `data` 폴더가 자동으로 생겨요. **모든 파일이 이 폴더 하나 안에** 있어요.

```
웨딩 사진 셀렉/
├── 웨딩 사진 셀렉 시작      ← 더블클릭해서 실행 (Windows 는 .exe)
├── 사진/                    ← 스튜디오 원본 사진
└── data/                    ← 점수 · 설정 · 미리보기 · Tailscale 로그인
```

> ⚠️ 바탕화면이 **iCloud(데스크탑 동기화) / OneDrive** 와 동기화되고 있다면 사진이 클라우드에도 올라가요.
> 원치 않으면 폴더를 홈 폴더나 `C:\` 같은 다른 곳에 두세요. 어디에 둬도 똑같이 동작해요.

### 실행되면

- 브라우저에 **http://127.0.0.1:8765/admin** (관리 화면) 이 열립니다.
- **검은(터미널) 창을 닫으면 프로그램이 꺼집니다.** 셀렉하는 동안은 켜두세요.
- 브라우저가 안 열리면 주소창에 `127.0.0.1:8765/admin` 을 직접 입력하세요.
- 다음에도 **`웨딩 사진 셀렉 시작`** 을 더블클릭하면 이어서 쓸 수 있어요 (점수 그대로).

## 사용 순서

관리 화면에서 위에서부터 차례대로:

### 1. 신랑 · 신부
이름과 **각자의 비밀번호**를 정하고 저장합니다. 비밀번호로 누가 로그인했는지 구분하니 서로 다르게 정하세요.

### 2. 사진 넣기
- 사진을 관리 화면에 **끌어다 놓거나** "사진 고르기 / 폴더째 고르기"
- 또는 **📂 사진 폴더 열기** 를 눌러 열리는 폴더에 사진을 복사 → **↻ 다시 불러오기**

처음엔 빠른 넘김을 위한 미리보기를 만드느라 몇 분 걸려요 (그동안에도 셀렉 가능).

### 3. 외부에서 접속하기 (선택)
이 컴퓨터에서만 볼 거면 건너뛰세요. 휴대폰이나 배우자가 접속하려면:

1. **외부 공유 시작** 클릭 → 뜨는 창에서 Tailscale 로그인 (Google / Apple / Microsoft 계정으로 무료 가입)
2. 처음 한 번은 **Funnel 허용** 창이 뜰 수 있어요 → 허용(Enable) 클릭
3. `https://wedding-select.xxxx.ts.net` 주소가 나오면 **복사** 해서 배우자에게 보내기 (비밀번호는 따로!)

다음에 프로그램을 켜면 자동으로 다시 공유돼요. 이 컴퓨터가 꺼지거나 잠자기에 들어가면 접속이 끊기니,
셀렉하는 기간에는 전원을 연결해 두고 잠자기를 꺼 두는 게 좋아요.

### 4. 셀렉!
**셀렉 화면 열기** (또는 공유 주소) → 비밀번호 입력 → 넘기면서 별점 → 마음에 들면 ♥ 최종셀렉
→ 메뉴(☰) → **최종셀렉 원본 다운로드** 로 zip 받아서 스튜디오에 전달.

## 🗑 삭제하는 법

모든 것이 **`웨딩 사진 셀렉` 폴더 하나**에 들어 있어서, 그 폴더만 지우면 컴퓨터에 아무것도 남지 않아요.

1. 필요하면 먼저 **최종셀렉 원본 다운로드** (폴더를 지우면 사진 · 점수도 함께 지워져요)
2. 외부 공유를 썼다면 관리 화면 3번에서 **Tailscale 로그아웃** (공개 주소가 바로 꺼져요)
3. 관리 화면 맨 아래 **프로그램 종료** (또는 검은 창 닫기)
4. **`웨딩 사진 셀렉`** 폴더를 휴지통에 버리기
5. (선택) [Tailscale 기기 목록](https://login.tailscale.com/admin/machines)에 꺼진 채로 남아 있는 **wedding-select** 기기를 **⋯ → Remove** 로 삭제

Tailscale 계정까지 없애고 싶다면 [Tailscale 설정](https://login.tailscale.com/admin/settings/general) 맨 아래에서 삭제할 수 있어요 (선택).
관리 화면 맨 아래 **🗑 삭제하는 법** 에도 같은 안내가 있어요.

## 자주 묻는 질문

**이상형 월드컵은 어떻게 진행되나요?**
메뉴(☰) → 🏆 이상형 월드컵 → 후보와 남길 장수(예: 40장)를 정하면 두 장씩 나와요. 더 마음에 드는 쪽을 누르면 다른 쪽은 빠지고,
(후보 수 − 남길 장수) 번 고르면 끝나요. 중간에 ✕ 로 나가도 저장돼서 메뉴에서 **이어하기** 할 수 있고, ↶ 로 바로 전 선택을 되돌릴 수 있어요.
각자 따로 진행하고, 결과는 공용 ♥ 최종셀렉에 추가하거나 교체할 수 있어요.

**실수로 초기화했어요!**
관리 화면 → 셀렉 초기화 → **↶ 마지막 변경 되돌리기**. 초기화 · 최종셀렉 교체 직전 상태가 `data/backups/` 에 자동 저장돼요 (최근 30개).

**사진이 어디에 저장되나요?**
`웨딩 사진 셀렉` 폴더 안의 `사진/` 폴더입니다.
점수·설정은 `data/` 폴더에 있어요. 다른 서버로 올라가지 않습니다.

**안전한가요?**
- 관리 화면은 이 컴퓨터(127.0.0.1)에서만 열리고, 외부 주소로는 열리지 않아요.
- 외부 주소는 비밀번호를 알아야 들어올 수 있고, 비밀번호를 10번 틀리면 30분간 로그인이 막혀요.
- 그래도 숫자 4자리보다는 **6자리 이상**을 추천해요. 셀렉이 끝나면 "공유 중지" 를 눌러 주세요.

**점수를 초기화하고 싶어요 / 다른 커플이 쓰려면?**
프로그램을 끄고 `data/scores.json` 을 지우면 점수가 초기화돼요. 새로 시작하려면 `사진/` 과 `data/` 폴더를 지우세요 (또는 zip 을 새로 풀어서 사용).

**새 버전으로 바꾸려면?**
새 zip 의 `웨딩 사진 셀렉 시작` 파일만 기존 폴더에 덮어쓰면 돼요. 사진 · 점수는 그대로 유지돼요.

**외부 공유 시작을 눌렀는데 주소가 바로 안 나와요**
처음 한 번은 주소가 인터넷에 등록되고 보안 인증서가 발급되느라 1~3분 걸려요. 프로그램이 바깥에서 실제로 접속되는지
확인한 뒤에 주소를 보여주니 조금만 기다려 주세요. (미리 접속하면 한동안 "사이트를 찾을 수 없음" 이 남을 수 있어서 숨겨 둬요.)
이미 다른 기기에 같은 이름(`wedding-select`)을 쓰고 있다면 주소가 `wedding-select-1` 처럼 바뀔 수 있어요. 관리 화면에 나온 주소를 쓰면 돼요.

**Tailscale 이 뭔가요?**
내 컴퓨터를 안전하게 인터넷 주소로 연결해 주는 서비스예요. 개인 사용은 무료이고, 이 프로그램에 내장돼 있어서 따로 설치할 필요가 없어요.
(이 프로젝트는 Tailscale 과 무관한 개인 프로젝트입니다.)

**포트를 바꾸고 싶어요**
8765 가 사용 중이면 자동으로 8766, 8767… 을 씁니다. 실행 창에 실제 주소가 표시돼요.

## 개발자용

Go (go.mod 의 버전) 필요. 외부 런타임 의존성 없음 (웹 UI 는 `web/` 를 바이너리에 내장).

```sh
go run .                       # 현재 폴더에 사진/ data/ 생성, 127.0.0.1:8765
# 빌드한 실행 파일은 어디서 실행하든 "실행 파일이 있는 폴더" 에 사진/ data/ 를 만듦
go run . -dir ~/my-wedding -port 9000 -no-browser
scripts/build.sh               # dist/ 에 macOS(유니버설) · Windows zip, Linux 바이너리 (macOS 에서 실행)
```

| 파일 | 내용 |
|---|---|
| `main.go` | 시작, 폴더 준비, 브라우저 열기 |
| `web.go` | HTTP 핸들러 (로컬: 전체 / Funnel: 셀렉 화면만), 로그인, 다운로드, 업로드 |
| `photos.go` | 사진 스캔, EXIF 회전, 미리보기 생성 (순수 Go) |
| `ts.go` | 내장 Tailscale (tsnet) 로그인 → Funnel 공개 |
| `store.go` | 설정 · 점수 JSON 저장 |
| `web/` | 셀렉 화면 (`index.html`, `app.js`) · 관리 화면 (`admin.html`, `admin.js`) |

`v*` 태그를 푸시하면 GitHub Actions 가 빌드해서 Release 에 올립니다.
