사용법

  • 좌우로 스와이프해서 넘기기
  • 두 손가락 핀치로 확대/축소, 더블탭으로 빠른 확대

  • 🏆 이상형 월드컵: 두 장 중 하나를 계속 고르면 원하는 장수만 남겨줘요. 사람마다 따로 저장되고, 별 옆에 사진별 몇 승 몇 패인지 보여요 (PC: ← → 로 선택, Backspace 되돌리기)
  • PC: ← → 이동, 1~5 점수, 0 취소, F 최종셀렉, G 목록
